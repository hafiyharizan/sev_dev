# UI/UX Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Polish Navbar, Banner, Pengumuman, Buletin, and Galeri sections — smooth transitions, fix structural issues, and remove dead CSS — while preserving the original design and theme.

**Architecture:** Six independent file changes (5 components + 1 CSS file). No new dependencies. Each task is self-contained and commits on its own. Verification after each task is `npx tsc --noEmit` + visual check in `npm run dev`.

**Tech Stack:** Next.js 14, React 18, Tailwind CSS 3.3.2, @headlessui/react 1.7.x, TypeScript 5.
